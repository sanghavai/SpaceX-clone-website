# 🚀 SpaceX Clone Website

This is a simple front-end clone of the SpaceX website built using only HTML, CSS, and JavaScript. It was created as a personal practice project to improve my web development skills and understand layout design and styling.

## 📌 Features

- Homepage layout inspired by the real SpaceX site
- Responsive design using CSS Flexbox
- Smooth scrolling and basic interactive elements
- Clean and structured code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
